## Other verified lab boundaries

- **Context:** The console printed the exact three context messages: fixed instructions, quoted passages with provenance, current question. See `01_CONTEXT_MAP.md`.
- **Tool confirmation:** The UI proposed `book_slot(date=2026-11-14, minutes=90)` with the human-readable text “Add a 90-minute revision slot on Sat 14 Nov 2026?”; `schedule.json` was absent before confirmation. Confirm returned `{"status":"ok","id":"slot_1","total_slots":1}` and added one local slot. `tool_log.jsonl` has its confirmed call/result.
- **Invalid tool request:** `book_slot(date=2026-11-14, minutes=900)` failed `tools.valid` with “minutes must be between 15 and 180”. There was no Confirm button and no schedule entry for the invalid call; the refusal was separately recorded in `tool_log.jsonl` as **not confirmed**.
- **Image answer:** `sample_images/sample_poster.png` returned the mock claim `14 November, 12:00`, **confidence 0.86**, and the supporting visible text.
- **Image refusal:** `sample_images/sample_noticeboard.png` produced a visible refusal: no requested deadline can be read and the image contains a named person's mark that should not be read out. No deadline was invented and no confidence was displayed as though there were an answer.

**Why the threshold is 0.25:** This threshold is supplied by the lab's integration instructions and used as a manual, corpus-specific screening rule. It is not calibrated as a probability or an accuracy guarantee. Testing on a larger corpus would be needed before using it generally.
