section: 2.3 Independence
updated: 2026-09-20

Events A and B are independent if P(A∩B) = P(A)P(B). Independence is a statement about probabilities, not about whether the events can happen together.

If A and B are mutually exclusive and both have positive probability, they cannot be independent, because P(A∩B) = 0 while P(A)P(B) > 0.

If either event has probability zero, then P(A)P(B) = 0 = P(A∩B), so mutually exclusive events of this kind are also independent.
